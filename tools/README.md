# Pin video tools

`make_video_pin.py` turns a finished 1:2 pin image into a 6-second, 1080x2160 video pin.
Videos live in the repo root and are served by GitHub Pages at
`https://racheloostdyk.github.io/pin-videos/<file>.mp4` for Pinterest bulk-upload CSVs.

Requires Python 3 with Pillow, and ffmpeg.
